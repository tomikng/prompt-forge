## What the forge sent

**V1** (ask+answer)

```text
Make the ordersPageRows in src/orders.js faster. Do not modify src/api.js.
```

Questions it asked:

- What do you mean by "the orders page"—what file or component is it? (e.g. `OrdersPage.js`, a URL path)
- When you say it's slow, what do you see? (e.g. page takes 5 seconds to load, buttons lag, list scrolling stutters)
- Are there any error messages in the browser console or network tab?

**V2** (ask+answer)

```text
Fix the cart total calculation in src/cart.js. When people buy more than one of an item, the cartTotal should multiply the price by the quantity. It currently does not account for quantity.
```

Questions it asked:

- What file contains the cart total calculation?
- Do you have an example of the wrong total (e.g., "buying 2 items at $10 each shows $15 instead of $20")?

**V3** (ask+answer)

```text
Fix the signup function to reject junk emails. The `validateSignup` function in src/signup.js should reject emails that are not shaped like name@domain.tld.
```

Questions it asked:

- What counts as a "junk email" for your use case—invalid format (missing @), disposable email domains (temp-mail.com etc.), or something else?
- Where is the signup code—what file or endpoint should I look at?
- What should happen when junk email is detected—reject it, show an error message, or something else?

**A1** (ask+answer)

```text
Rename the getUser function to findUserById in src/users.js, everywhere it's used.
```

Questions it asked:

- What is "it"? (a variable, function, file, folder, or something else?)
- What should the new name be, or what makes a name "clearer" in your case?
- Where should I look for this—a specific file or project?

**C1** (unchanged)

```text
In src/users.js rename getUser to fetchUser and update every call site; run npm test and make sure it passes.
```

**C2** (rewrite)

```text
In src/cart.js, make cartTotal multiply each item's price by its quantity. Add a test case to test/cart.test.js with quantity 3. Then run npm test to verify.
```
